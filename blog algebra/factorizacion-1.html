Factorización I

Factorizar es convertir una suma o una resta en una multiplicación. Por eso se dice que es el proceso inverso de desarrollar productos notables.

1. Factor común

Se reconoce porque todos los términos tienen algo que se repite, como un número, una letra o las dos cosas. Ese elemento se coloca fuera del paréntesis.

Para hacerlo, busco el máximo factor que se pueda dividir entre todos los términos. Después divido cada término entre ese factor y escribo los resultados dentro del paréntesis.

Ejemplo: 12x³ - 18x²

  1. El número común más grande es 6 y la menor potencia de x es x².
  2. El factor común es 6x².
  3. 12x³ ÷ 6x² = 2x y 18x² ÷ 6x² = 3.
  4. Resultado: 12x³ - 18x² = 6x²(2x - 3).

Comprobación multiplicando de regreso

6x²(2x - 3) = 6x²(2x) - 6x²(3) = 12x³ - 18x².

2. Trinomio cuadrado perfecto

Tiene tres términos. El primero y el último son cuadrados perfectos, y el término de en medio es el doble de multiplicar sus raíces cuadradas.

Saco la raíz del primer y del tercer término. Luego reviso si el término de en medio coincide con el doble de esas raíces. Si coincide, escribo un binomio al cuadrado.

a² + 2ab + b² = (a + b)²

Ejemplo: x² + 14x + 49

  1. La raíz de x² es x y la raíz de 49 es 7.
  2. Compruebo el término de en medio: 2(x)(7) = 14x.
  3. Como coincide, el trinomio es perfecto.
  4. Resultado: x² + 14x + 49 = (x + 7)².

Comprobación multiplicando de regreso

(x + 7)² = (x + 7)(x + 7) = x² + 7x + 7x + 49 = x² + 14x + 49.

3. Diferencia de cuadrados

Se reconoce porque hay dos términos restándose y ambos son cuadrados perfectos. No funciona igual si hay una suma.

Saco la raíz cuadrada de cada término. Después formo dos paréntesis: uno con suma y otro con resta de esas raíces.

a² - b² = (a + b)(a - b)

Ejemplo: 25m² - 64

  1. La raíz de 25m² es 5m y la raíz de 64 es 8.
  2. Como hay una resta entre dos cuadrados, uso suma y resta.
  3. Resultado: 25m² - 64 = (5m + 8)(5m - 8).

Comprobación multiplicando de regreso

(5m + 8)(5m - 8) = 25m² - 40m + 40m - 64 = 25m² - 64.

Ida y regreso

Factorizar es hacer el camino de regreso: parto de una expresión desarrollada y la convierto en factores. Si multiplico esos factores, regreso a la expresión original.
