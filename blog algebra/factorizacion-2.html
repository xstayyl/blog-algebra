Factorización II

En esta entrada continúo con otros casos de factorización. La idea es observar la forma del polinomio para elegir el procedimiento que corresponde.

1. Suma y diferencia de cubos

Se reconoce porque hay dos términos y los dos son cubos perfectos. Si están sumando, es una suma de cubos; si están restando, es una diferencia de cubos.

Primero saco la raíz cúbica de cada término. Después uso dos factores: el primero es un binomio con esas raíces y el segundo tiene tres términos.

a³ + b³ = (a + b)(a² - ab + b²)

a³ - b³ = (a - b)(a² + ab + b²)

Ejemplo: 8x³ + 125

  1. La raíz cúbica de 8x³ es 2x y la de 125 es 5.
  2. Es una suma, así que el primer factor es (2x + 5).
  3. El segundo factor queda (4x² - 10x + 25).
  4. Resultado: 8x³ + 125 = (2x + 5)(4x² - 10x + 25).

Comprobación multiplicando de regreso

(2x + 5)(4x² - 10x + 25) = 8x³ - 20x² + 50x + 20x² - 50x + 125 = 8x³ + 125.

2. Trinomio x² + bx + c

Tiene tres términos y el coeficiente del primer término es 1. Para reconocerlo, busco dos números que al multiplicarse den c y al sumarse den b.

Esos dos números se convierten en los términos de los paréntesis. Reviso los signos para que la suma y el producto coincidan con el trinomio original.

Ejemplo: x² + 9x + 20

  1. Necesito dos números que multiplicados den 20 y sumados den 9.
  2. Esos números son 4 y 5, porque 4 · 5 = 20 y 4 + 5 = 9.
  3. Resultado: x² + 9x + 20 = (x + 4)(x + 5).

Comprobación multiplicando de regreso

(x + 4)(x + 5) = x² + 5x + 4x + 20 = x² + 9x + 20.

3. Trinomio ax² + bx + c: aspa simple

Aquí el primer término tiene un número diferente de 1. Para reconocerlo, hay tres términos y se necesita encontrar una forma de que los productos cruzados sumen el término de en medio.

En el aspa simple busco dos factores para el primer término y dos para el último. Después pruebo los productos cruzados hasta que su suma sea el término de en medio.

Ejemplo: 6x² + 11x + 3

  1. Para 6x² puedo usar 3x y 2x. Para 3 puedo usar 1 y 3.
  2. Pruebo los productos cruzados: 3x · 3 = 9x y 2x · 1 = 2x.
  3. La suma es 9x + 2x = 11x, que coincide con el término de en medio.
  4. Resultado: 6x² + 11x + 3 = (3x + 1)(2x + 3).

Comprobación multiplicando de regreso

(3x + 1)(2x + 3) = 6x² + 9x + 2x + 3 = 6x² + 11x + 3.

Estrategia de factorización

Para decidir qué método usar, sigo estos pasos:

  1. Primero reviso si todos los términos tienen un factor común.
  2. Si hay dos términos, compruebo si son cubos perfectos.
  3. Si hay tres términos y empieza con x², busco el trinomio x² + bx + c.
  4. Si hay tres términos y empieza con ax², uso el aspa simple.
  5. Al final multiplico los factores para comprobar que regreso al polinomio original.

La cantidad de términos ayuda a orientarme, pero siempre debo revisar los productos y los signos antes de decidir que la factorización está completa.
